## 一、先认识一下这个站点

博客门户是一个**独立的博客站点**，不是若依后台里的一个菜单：

- 打开就是文章，左边是文章流，右边是博主卡片、热门文章、分类、标签、最新评论。
- **不登录也能看**：文章列表、搜索、分类、标签、归档、文章详情、评论都能浏览。
- **要登录才能写**：发评论、写文章、管理自己的文章。
- 外观和若依后台完全不同，没有侧边栏菜单、没有标签页，只有一个普通博客该有的样子。

### 地址

| 环境 | 门户地址 | 说明 |
| --- | --- | --- |
| DEV（开发） | `http://localhost:80/portal/home` | 日常开发 |
| UAT（验收） | `http://localhost:81/portal/home` | 与 DEV 数据完全隔离，页头有 `UAT` 标识 |

### 账号从哪来

门户没有注册功能，账号由管理员在**若依后台 →「系统管理 → 用户管理」**创建并分配角色：

- 角色 `admin`（管理员）：可以发布/审核文章，能进后台。
- 其他角色（普通用户）：可以写文章，但提交后要等管理员审核。

> 忘了密码？请管理员在后台「用户管理 → 重置密码」处理。

## 二、作为读者：逛博客

### 1. 首页

打开门户就是首页，从上到下依次是：

1. **顶部横幅**：站点标题、副标题，以及文章数 / 分类数 / 标签数 / 阅读量。
2. **搜索框**（横幅右侧）：输入标题或摘要里的关键词，回车或点「搜索」。
3. **分类筛选**：`全部` + 每个分类（后面小数字是该分类文章数），点一下就筛选。
4. **排序**：`最新`（默认）、`热门`（按阅读量）、`评论`（按评论数）。
5. **文章列表**：每条包含标题、摘要、标签、作者、日期、分类、阅读数、评论数；带「置顶 / 推荐」标记的会显示在标题前。
6. **分页**：文章多时出现在列表底部。
7. **右侧栏**：博主信息与统计、热门文章、文章分类、标签云、最新评论，都可以点。

筛选条件会写进地址栏（例如 `?categoryId=1`、`?tagId=1&month=2026-10`），**复制给别人也能看到同样的结果**。筛选生效时列表上方会出现一条提示，点「清除筛选」可以一键复原。

### 2. 搜索

- 顶部搜索框（任何页面都有）：输入关键词后回车，跳到首页搜索结果。
- 搜索范围：文章**标题 + 摘要**。
- 没结果时会提示「没有匹配的文章，换个条件试试」。

### 3. 分类 / 标签

- 点分类 chips 或侧栏「文章分类」→ 只看该分类。
- 点标签云里的标签，或文章详情底部的标签 → 只看该标签。
- 空分类/空标签不会出现在门户里（有人发过文章才会显示）。

### 4. 归档

顶部导航「归档」→ 左边按月份列出（带篇数），点某个月，右边显示当月文章；地址里会带 `?month=2026-10`，可分享。

### 5. 阅读文章

点任意文章卡片进入详情页：

- 正文是 Markdown 渲染的（标题、列表、表格、代码块、公式、流程图都正常显示）。
- 顶部有作者、发布时间、分类、阅读数、评论数；底部是标签。
- 页面下方是评论区；右侧是博主卡和热门文章。

### 6. 发表评论

- **未登录**：评论区显示「登录后即可参与评论」和一个「登录」按钮。
- **已登录**：出现输入框（最多 1000 字），点「发表评论」，成功后会立刻出现在列表里。
- 评论会显示昵称和时间；只显示正常状态的评论（被管理员隐藏的不会出现）。

## 三、作为普通用户：写文章

### 1. 登录

两种入口，效果一样：

- 顶栏右侧「登录」按钮 → 进入门户登录页。
- 直接访问 `/portal/login`。

输入账号密码 → 登录成功后回到门户（如果是点了「写文章」被要求登录，会**自动回到写作页**）。

> 登录页右下角有「管理员入口」，那是给管理员进若依后台用的；你不需要它。
> UAT 环境还会多出「以管理员/普通用户进入」两个免密按钮，只在测试环境出现。

登录后顶栏右侧变成你的头像和昵称，点开有：`我的文章`、`写文章`、`退出登录`。

### 2. 写第一篇文章

1. 顶栏点「写文章」（或在「我的文章」页点「写新文章」）。
2. 填写：
   - **标题**（必填，最多 200 字）
   - **分类**（下拉选择，可不选）
   - **摘要**（列表页展示，建议 1-2 句，最多 500 字）
   - **标签**（可多选）
   - **封面图**（可选）：填图片地址，或点「上传封面」直接传一张
3. 在编辑器里写正文，支持 Markdown：
   - 工具栏有加粗、斜体、删除线、标题、引用、列表、代码、表格、链接、图片等按钮；
   - 支持粘贴/拖拽/上传图片（图片会自动上传到博客服务并插入 Markdown）；
   - 支持代码块高亮、表格、公式（KaTeX）、流程图（Mermaid）。
4. 想先看看效果，点「预览」弹出预览窗口（弹窗右上角可以最大化）。
5. 保存：

| 按钮 | 作用 | 结果 |
| --- | --- | --- |
| **保存草稿** | 只保存，不公开 | 状态「草稿」，门户首页看不到；随时可以回来改 |
| **提交审核** | 提交给管理员 | 状态「待审核」，管理员通过后变成「已发布」并出现在门户 |
| 立即发布 | **只有管理员**才有 | 状态「已发布」，立刻出现在门户 |

> 普通用户即使想办法传「已发布」，后端也会强制转成「待审核」——不存在绕过审核的路径。

6. 保存成功会自动跳到「我的文章」，可以在那里看到状态。

### 3. 我的文章

顶栏头像 →「我的文章」（或直接访问 `/portal/me`）：

- 顶部按状态筛选：`全部` / `草稿` / `待审核` / `已发布` / `已驳回`。
- 每篇文章一行：状态标签、标题、分类、标签、时间、阅读数、评论数。
- 可做的操作：
  - **编辑**：回到写作页继续改（草稿、待审核、已驳回都可以改）。
  - **提交审核**：草稿或已驳回的文章，点一下提交给管理员。
  - **查看**：只有「已发布」才有，跳到门户里的文章详情页。
  - **删除**：会二次确认，删除后不可恢复。

> 这里只会出现**你自己的**文章。别人的草稿、待审核文章在任何入口都看不到。

### 4. 状态说明

| 状态 | 含义 | 门户里能看到吗 | 你需要做什么 |
| --- | --- | --- | --- |
| 草稿 | 只保存了，没提交 | 否 | 写完了点「提交审核」 |
| 待审核 | 已提交，等管理员处理 | 否 | 等管理员审核 |
| 已发布 | 已公开 | **是** | 无 |
| 已驳回 | 管理员没通过 | 否 | 按驳回意见改完，再「提交审核」 |

## 四、作为管理员：发布与审核

管理员和普通用户的区别只有三点：写作页多一个「立即发布」、门户上有「管理后台」入口、能在后台审核别人的文章。

### 1. 从门户进后台

- 顶栏导航「管理后台」；
- 或头像菜单「进入管理后台」；
- 或页脚「管理员登录」。

三个入口都指向若依后台，**门户和后台是同一套登录态，不需要再登录一次**。

### 2. 审核普通用户的文章

在若依后台左侧菜单：**博客管理 → 文章管理**。

找到状态为「待审核」的文章，操作列有：

| 按钮 | 作用 |
| --- | --- |
| **通过** | 状态改为「已发布」，门户立刻可见 |
| **驳回** | 状态改为「已驳回」，作者可以在「我的文章」里看到并修改 |
| **发布** | 直接把非已发布文章改成「已发布」 |
| **下架** | 把「已发布」改回「草稿」，门户立刻不可见 |
| 查看 / 编辑 / 删除 | 与列表页一致 |

> 文章管理页支持按标题、状态、分类、时间筛选，也可以批量删除。

### 3. 管理分类 / 标签 / 评论

同一组菜单下还有「分类管理」「标签管理」「评论管理」：

- 分类、标签：新增/编辑/排序/删除；门户只展示**有已发布文章**的分类和标签。
- 评论：审核（正常/隐藏）、删除；门户只展示正常状态的评论。

### 4. 站点标题

门户的站点标题、副标题来自后端配置，改 `blog-service` 的：

```
BLOG_PORTAL_TITLE     默认：CDPersonal 的博客
BLOG_PORTAL_SUBTITLE  默认：记录、思考与分享 —— 写代码，也写生活
```

改完重启 blog-service 生效；门户有 60 秒缓存，刷新或等一分钟即可看到。

## 五、UAT 测试环境

UAT 是独立的一套（端口 81），数据与 DEV 完全隔离，页头有橙色 `UAT` 标识。

- 访问：`http://localhost:81/portal/home`
- 登录页额外提供**免密进入**：「以管理员进入」「以普通用户进入」，不用记密码。
- 适合演示、验收、培训；在这里乱改不会影响 DEV 数据。
- 启动/停止方式见 [`backend/uat-service/README.md`](../../backend/uat-service/README.md)。

## 六、常见问题（FAQ）

**Q1：打开门户一个文章都没有？**
按顺序看：① 先确认 `blog-service` 已经重启到新代码（后端改过就要重启）；② `scripts\dev-status.ps1` 看 8010/8889（DEV）或 8011/8890（UAT）是否在听；③ 若服务正常但仍为空，说明确实还没有「已发布」文章，去后台发布一篇。

**Q2：我点了「写文章」却被要求登录？**
写作、我的文章需要登录。登录后会自动回到你刚才想去的页面，不用重新点。

**Q3：文章保存了，门户首页却看不到？**
草稿和待审核都不会公开。去「我的文章」确认状态，草稿要点「提交审核」，等管理员通过后才出现。

**Q4：提交审核很久没动静？**
需要管理员在后台「博客管理 → 文章管理」里点「通过」。可以提醒管理员，或让管理员在门户写作页直接用「立即发布」。

**Q5：文章被驳回了怎么办？**
「我的文章」里状态会显示「已驳回」，点「编辑」修改后，再点「提交审核」。

**Q6：评论发不出去 / 看不到别人的评论？**
发评论必须登录；看不到评论可能是被管理员隐藏了，或那篇文章还没发布。

**Q7：图片显示不出来？**
图片存在博客服务的上传目录，通过 `/profile/blog/**` 访问。如果图片 404，通常是 blog-service 没启动或图片被清理了；重新上传一次即可。

**Q8：为什么门户没有后台那些菜单？**
门户是给读者看的独立站点，故意不带侧边栏和标签页。需要管理功能时，用顶栏/头像菜单里的「管理后台」进入若依。

**Q9：我修改了文章，门户上还是旧的？**
保存后需要重新进入文章详情（或刷新）。如果状态从已发布改成了草稿，门户会立刻看不到这篇文章。

**Q10：UAT 里改了数据，会影响 DEV 吗？**
不会。UAT 用的是独立数据库 `ry-cloud-uat` 和 Redis db1，与 DEV 完全隔离。

**Q11：门户能注册账号吗？**
不能。账号统一由管理员在后台创建，避免公开注册带来的垃圾账号。
